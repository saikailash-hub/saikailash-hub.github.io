# Sai Kailash Portfolio

A static personal portfolio for Chadhuvula Sai Kailash.

## Project structure

- `index.html` — website structure and content
- `style.css` — premium engineering/blueprint visual design
- `script.js` — navigation, scroll reveal, certificate lightbox
- `assets/profile.jpg` — add your real professional profile photo here
- `assets/certificates/` — add the real certificate images here

## GitHub Pages

This is a plain HTML/CSS/JS site and does not require Node.js, npm, React, or a build step.

Upload the contents of this project to the root of the `saikailash-hub.github.io` repository. Then enable GitHub Pages from:

Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: / (root)

The expected site URL is:

https://saikailash-hub.github.io/
